# Internationalization

The account center owns the preferred language. `GET /api/v1/me` returns the live SSO `user.preferredLanguage`; the business database does not store another copy. Supported account values are `zh-hans`, `en`, `ja`, and `ko`. The frontend normalizes them to BCP 47 tags (`zh-Hans`, `en`, `ja`, `ko`). Missing or unsupported values resolve to Simplified Chinese. Neither browser language nor local storage overrides an account preference.

The existing session focus/visibility refresh synchronizes changes made in the account center. Logging out restores Chinese. Language changes must not remount routes, refetch song data, or reset upload/edit drafts.

## Translation resources

- `src/i18n.ts`: the configured i18next instance, normalization and formatting locale.
- `src/locales/{zh-Hans,en,ja,ko}.json`: bundled resources; Chinese is the fallback catalogue.
- `src/i18next.d.ts`: checked translation keys. React components subscribe with `useTranslation`; non-React utilities translate at call time.
- `src/api/error-message.ts`: translates stable API error codes. Server prose is not a translation key; Chinese preserves detailed original messages, other languages use localized error codes and available line numbers.

Use descriptive, stable keys and complete sentences with named interpolation parameters. Never concatenate translated sentence fragments. Use `_one`/`_other` and `count` for pluralized English messages. React escapes values; never inject translations or metadata using `dangerouslySetInnerHTML`. Keep native language names and user-authored content unchanged. Dates and score numbers use the active `Intl` locale; `DocumentLanguage` updates the document language and title.

## Song names

`chartText` selects the title and subtitle independently:

1. The SSO preferred language in the complete translation dictionary, including `en`; Chinese maps to `zh`.
2. The dictionary’s `en` value.
3. Original TJA `title`/`subtitle`.

An unset account preference defaults to Chinese before selecting song text. Missing Japanese or Korean text falls back to English, then the original field. The API always returns all stored translations, independent of request language.

Missing, empty or whitespace-only values fall through. TJA `--`/`++` subtitle markers are removed for display. Lists, details, cover descriptions, canvas previews, upload previews and replacement confirmations share this function. Editing all four languages writes `titleTranslations` / `subtitleTranslations`; null restores the language from the current TJA. Downloads retain original file bytes. Do not overwrite chart metadata with display strings.

## Checks

```sh
pnpm test
pnpm lint
pnpm format:check
pnpm build
# Against a local Vite server; uses isolated HTTP fixtures, no account mutations.
pnpm exec playwright test e2e/i18n.spec.ts
```

The tests check catalogue/placeholder parity, pluralization, language normalization, API error messages, TJA localized metadata, title/subtitle fallback, four-language mobile rendering, session refresh and draft preservation.
